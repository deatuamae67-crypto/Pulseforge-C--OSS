# Optional UI media

The complete DevCore contains optional audio-visualizer PNG symbols. PulseForge retains the visualizer implementation and settings in the OSS build. The default star visualizer has a vector fallback, so absence of a local PNG never blocks gameplay.

Binary UI media whose redistribution terms are not part of the Apache-2.0 source grant is intentionally kept outside the public OSS package. Local installs can provide the expected files under this directory.

# PulseForge built-in mods

The directories in this `mods/` tree are part of the PulseForge Complete engine distribution. They are versioned with the engine rather than installed as optional external content packs.

Large/binary assets are stored through Git LFS; chart, script and configuration files remain normal Git files where practical. `modsList.txt` records the historical/default enablement state consumed by the engine catalog.

`../docs/complete/mods/*.json` and `../docs/MOD_CORPUS_1.0.0.json` are provenance/audit metadata for this tree. They do not replace the actual mod files.

Private signing material, secrets, build caches and proprietary Discord Social SDK binaries remain excluded from the repository.
